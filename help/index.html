Frequently Asked Questions

How do I earn XP?

Completed placements in Geometry Dash, Celeste, and Beat Saber contribute to one profile level. Matching names in the same game count once, using the higher award. In-progress placements and personal list order have no effect.

How do Extreme Demon bonuses work?

The bonuses use a fixed set of recorded AREDL ranks. Extremes without a recorded rank receive the base award.

How do I search the guide?

Type letters from a game’s name in order. You can skip letters. For example, “bts” finds Beat Saber.
